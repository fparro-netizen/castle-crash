# Castle Crash

An original physics puzzle game for iPhone (and any browser). Drag back from the cannon to aim, release to fire, and knock the crowns and gems off the castle with a limited number of cannonballs.

- 24 hand-made levels, 1 to 3 stars each, coin bonus for unused balls
- Wood, stone and ice blocks with different strengths
- Works offline and full screen after Safari > Share > Add to Home Screen
- No ads, no purchases, no tracking

Built with HTML5 canvas and [Matter.js](https://brm.io/matter-js/) (MIT, bundled in `js/`).
